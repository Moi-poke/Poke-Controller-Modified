# シリアルモニタ

マイコンとの送受信を眺める小窓。メニュー→「シリアルモニタ」で開く。

## 見えるもの

- Tx（PC→マイコン）とRx（マイコン→PC）の時系列。受信は1つの読み取り役が配るため、開きっぱなしでも応答の横取りはしない。
- フィルタ切替：「通常のみ」「全部」「mon のみ」「エラー・状態のみ」。
- 窓内は有界キュー（上限2000行、120msごとに最大512行を描画）＋フィルタで絞る。溢れた古い行は捨て件数だけ状態欄へ出す。
- ファイル記録は `logger` へ残る。Rx は info、Tx は debug のため、既定では Rx 中心に残り Tx は debug 有効時に残る。一時停止・クリアしてもファイル側は止まらない・消えない。

## 使い方

1. 接続した状態でメニュー→「シリアルモニタ」を開く
2. フィルタで絞りながら流れを確認する（live Tx も全件キューへ積み、上限超過分は古い方から捨てる）
3. 閉じると窓だけ閉じる（接続はそのまま）

## 注意

- 表示は有界キュー＋フィルタで絞る。正確な全量は保存先ファイルで見る（Tx は debug 扱い）。
- 重い描画で本体が遅くなる場合は窓を閉じる。
