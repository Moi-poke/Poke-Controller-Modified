# ログ欄

メイン画面のログ欄の形と、各部の役割。実装は
`SerialController/ui/log_panel.py`（欄どうしの連携とポンプ）、
`SerialController/ui/log_view.py`（1欄ぶんの表示部品）、
`SerialController/core/log_model.py`（1行の型と水準の推定、tkinter なし）、
`SerialController/LogPane.py`（キューと標準出力の付け替え）。

## 形

```
┌ ログ │ 入力 ┐
│ 上の欄：すべての出力（時系列）                        │
│  22:33:48.954 探索中... 39 回目                        │
│  22:33:48.954 待機中... ×6                             │
│  22:33:48.954 ▶ 見つかった: 色違い 3体目               │  ← print2（結果）
│  22:33:48.954 ✖ FileNotFoundError: ...                 │  ← traceback の塊は赤
├─ 結果とエラー（4）                         [消去] ─────┤
│ 下の欄：残しておきたい行だけ                           │
│  ▶ 見つかった: 色違い 3体目                            │  クリックで上の欄の
│  ✖ FileNotFoundError: ...                              │  その時点へ移動
└────────────────────────────────────────────────────────┘
 [検索（Ctrl+F）][▲][▼] 3/12            [✖ 2][⚠ 1][表示 ▾]
```

| 部分 | 役割 |
|---|---|
| 上の欄 | `print`・`print2`・logger の ERROR 以上をすべて時系列で。末尾にいる間だけ追従し、上へ読みに行くと止まって「↓ 新着 N 行」ボタンが出る |
| 下の欄「結果とエラー」 | `print2` の出力、エラー・警告（traceback は例外名の1行だけ）、右クリックでピン留めした行。上の欄が上限で流れても残る |
| 入力タブ | シリアルへ送った操作。量の桁が違うので別タブ |
| 検索 | 選んでいる欄（最後にクリックした欄）を探す。Enter で次、Shift+Enter で前、Esc で解除。隠した行は数えない |
| ✖ / ⚠ | エラー・警告の件数。押すと上の欄の次の箇所へ |
| 「表示」メニュー | 種類ごとの表示（通常の出力・結果・警告・エラー）、時刻、折り返し、×N まとめ、エラーと警告を下に集める、入力ログの記録、コピー・保存・消去 |

## 水準の決め方

`print` には水準が無いので、本文から推定する（`LineClassifier`）。
**目印がある行だけ**を水準つきにし、普通の文は通常の出力のままにする。
誤ってエラー扱いにすると、赤色が警報として信用されなくなるため。

| 本文 | 水準 | 下の欄へ |
|---|---|---|
| `Traceback (most recent call last):` から例外名の行まで | エラー | 例外名の行だけ |
| `ERROR:` / `[ERROR]` / `エラー:` / `失敗:` で始まる | エラー | ○ |
| `WARNING:` / `[WARN]` / `警告:` で始まる | 警告 | ○ |
| `-- finished successfully. --` | 完了 | × |
| `-- 〜 --` | システム | × |
| `self.print2(...)` | 結果 | ○（全行） |
| `logger.error(...)` 以上 | エラー | 先頭の1行 |

スクリプトから確実にエラーとして見せたいときは、`print("ERROR: …")` と書く。

## 設定

`settings.ini` の `[Log View]`（`config.py` が既定値を持つ）。

| キー | 既定 | 意味 |
|---|---|---|
| `show_time` | True | 行頭に時刻（書かれた時刻、ミリ秒まで） |
| `wrap` | True | 長い行を折り返す（False なら横スクロール） |
| `group_similar` | True | 同じ行の連続を ×N にまとめる |
| `collect_problems` | True | エラーと警告を下の欄にも集める |

種類ごとの表示（絞り込み）は保存しない。次の起動で「行が出ない」と
迷わせないため。

## 参考にしたもの

- Prism Launcher（Minecraft ランチャー）のログ画面: 水準ごとの色分け、
  末尾へ戻るボタン、検索して次へ、コピー。
- ブラウザ開発ツールのコンソール: 同じ行のまとめ（×N）、水準での絞り込み、
  エラー・警告の件数。
- IDE の「問題」パネルと出力の関係: 下の欄から元の時点へ飛ぶ。

## 性能の前提

- 取り出しは 200ms ごと、1回最大 512 行を insert 1回でまとめて入れる。
- 絞り込みと時刻の表示切替は tag の `elide` で行い、中身を作り直さない。
- 上の欄は最新 5000 行だけを残す（Text は行数に比例して重くなる）。
  最初に捨てたとき、下の欄の見出しに一度だけ知らせる。
